# Rclone OAuth - Personal Application

This repository serves as the application homepage and privacy policy for a personal Rclone OAuth setup, as required by Google Cloud Platform.

## Project Overview
This application is created strictly for personal use. Its sole purpose is to allow the repository owner to connect their local Rclone instance to their own Google Drive account in order to backup and synchronize their own files. 

This is **not** a public application, nor is it a commercial backup service.

## Privacy Policy
1. **Data Collection:** This application does not collect, track, store, or share any personal data, credentials, or user information. 
2. **Data Usage:** The OAuth application only requests access to the owner's personal Google Drive for the purpose of executing standard Rclone commands (upload, download, sync) on their own files.
3. **Third-Party Sharing:** No data is shared with any third parties whatsoever.

## Google Cloud Configuration
When configuring the OAuth Consent Screen in Google Cloud, the following URLs are used:

* **Application home page:** `https://galoz11.github.io/rclone-oauth/`
* **Application privacy policy link:** `https://galoz11.github.io/rclone-oauth/`

*(Note: The same URL is used for both the homepage and the privacy policy, as all required information is contained on this single page).*
